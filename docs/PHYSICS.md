# 물리 모델 노트

- **좌표/단위**: SI(m, kg, s). 테이블 평면 x(긴 변)·y, 높이 z. 공은 위치, 선속도, 각속도(3축), 방향 쿼터니언을 가짐.
- **시간 적분**: 고정 1 ms 서브스텝. 각 스텝 안에서 공-공/쿠션/jaw 충돌 시각을 해석적으로 예측해 가장 이른 충돌부터 처리(터널링 없음).
- **슬라이딩→구름**: 접촉점 속도 u 가 0이 될 때까지 가속도 3.5·μs·g 로 선형 감소 후 구름(μr + 점성항)으로 자연 감속.
- **큐 타격**: 타점은 큐 축에 수직인 평면 (a,b)로 정의. 임펄스는 큐 축 방향, 팁 마찰 원뿔(μ_tip) 초과 시 miscue.
  squirt 는 엔드매스 모델, 엘리베이션은 천 바운스(점프)와 swerve(수평축 스핀+슬라이딩 마찰)로 자연 발생.
- **공-공**: 반발계수 0.95 + 접촉점 쿨롱 마찰(Alciatore 속도 의존 μ)로 throw·스핀 전달.
- **쿠션**: 노즈가 공 중심보다 높은 접점(높이비 0.637)에서 3D 임펄스 → 상하/좌우 스핀이 반사각·속도에 영향. 속도 의존 반발계수.
- **포켓**: 둥근 jaw tip 충돌(rattle) + 캡처 원.
- 모든 파라미터는 `src/config/physics.ts`; 게임 중 디버그 패널(일시정지 → 디버그 패널, 또는 `?debug`)에서 실시간 조절.
